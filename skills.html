    A question arrives.

    Through a conversational front end, such as a Copilot Studio agent in Teams or an app calling a FastAPI endpoint.

    Identity comes first.

    Microsoft Entra ID app registrations, OAuth 2.0 tokens and role-based access decide which documents this person may see.

    The agent plans.

    A LangGraph workflow decides whether to retrieve, which source to query and when to iterate. Simple lookups take a cheaper path.

    Hybrid retrieval.

    BM25 and vector search together, over PgVector or Pinecone, grounded in the organization’s own policies and SOPs.

    A grounded answer.

    Azure OpenAI writes the reply from what was retrieved, not from memory.

    Or an honest refusal.

    Confidence scoring and structured refusal kept out-of-scope hallucination under 3%, and every response is logged for audit.

    Measured before it ships.

    A 500+ query golden set in Ragas and LangSmith gates every prompt and model change in GitHub Actions, and the service runs on AKS.

Bars show time per op, so shorter is faster; the bandwidth bar shows how close the kernel gets to the hardware limit.

The problem

LLM inference spends its time in places you don’t expect. A faster kernel only helps if the kernel is where the time goes.

What I built

Fused RMSNorm + residual and SwiGLU kernels, written in Triton for NVIDIA and in Metal for Apple silicon. Roofline analysis then showed decode was dispatch-bound, not bandwidth-bound, which cancelled a planned GEMV kernel in favour of CUDA-graph capture. Benchmark tables are generated from committed runs and drift-checked in the build.

LLM billing and token-audit engine

FinOpsAI

Normalizes LLM usage logs from three providers, attributes the spend, forecasts the month-end invoice, and tells a gateway when to hold back.

  • Python
  • FastAPI
  • GitHub
  • Live dashboard
Usage stream Synthetic data, as in the project’s own demo

    Ask the pre-dispatch policy endpoint

    Pick a cost center and a model, then send the request.

    The problem

    LLM spend arrives as three different log formats, and as one surprise invoice at the end of the month.

    What I built

    An engine that normalizes OpenAI, Anthropic and Bedrock usage logs, attributes spend to cost centers, forecasts the month-end invoice, and serves a pre-dispatch policy endpoint that tells a gateway to allow, downgrade or block a call.

    Results

    The budgets and spend here are made up, like the project’s demo data. The rule: projected over budget means downgrade a large model; far over means block.

    The Gallery

    An agent that directs the Formula 1 world feed: a 10 Hz scorer and Gemini 2.5 Flash decide, live, which battle the cameras should be on.

      The problem

      A race has twenty cars and one broadcast feed. Passes get missed because they happen where the camera isn’t.

      What I built

      A deterministic Python scorer reads telemetry ten times a second, and Gemini 2.5 Flash, through Google ADK, takes those scores and cuts the feed. Gemini multi-speaker TTS and the Web Audio API switch between play-by-play and color commentary as the race unfolds, over FastAPI WebSockets, with Three.js track maps and Grafana Cloud MCP for telemetry and cut tracking.
